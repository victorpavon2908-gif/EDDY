# Evidencias de evolución del agente LEO

Inventario inicial: inventory.json (base e59c274). Validación reproducible: validation.json y logs por suite, ejecutados en servidor. Son pruebas reales con fixtures donde corresponde; no son mediciones del teléfono.

PENDIENTE DE VALIDACIÓN FÍSICA: consumo, CPU/RAM bajo carga real, temperatura, wake word, ASR/TTS, interrupción acústica, ruido, distancia, pantalla bloqueada, llamadas, Bluetooth y música. El recolector no marca estas propiedades como aprobadas automáticamente.
