# Instrucciones de trabajo para LEO

- Trabajar y entregar siempre en `main`, por indicación expresa del usuario. Sincronizar `origin/main` antes de empezar y comprobar que la entrega está publicada en `origin/main` antes de darla por terminada.
- No dejar una entrega únicamente en una rama secundaria ni en un pull request pendiente. Mantener el espacio de trabajo en `main` al finalizar.
- Entregar los cambios mediante commits en GitHub y devolver el enlace al commit.
- No generar, empaquetar, descargar ni subir APK como parte del trabajo, salvo que el usuario lo solicite expresamente de nuevo.
- La automatización de commits y pull requests ejecuta pruebas y Lint; no debe producir APK.
